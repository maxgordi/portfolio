# Job Agent — автопошук і автовідгуки на AI-вакансії

3 рази на день агент:
1. збирає нові вакансії з **Djinni, DOU, robota.ua, work.ua**;
2. відсіює непотрібне без LLM: не-AI ролі, QA, .NET, стажування, старі вакансії, компанії з чорного списку (приклад: казино, ставки, криптовалюти);
3. LLM оцінює кожну вакансію (0–100) щодо резюме й побажань кандидата (віддалено, рівень англійської, стек) і пише супровідний лист мовою вакансії;
4. на вакансії з балом ≥ 70 **сам відгукується**, прикріплюючи твоє CV: українське або англійське, залежно від мови вакансії;
5. надсилає звіт у Telegram: куди відправлено, що потребує ручного відгуку і що цікаве, але нижче порогу.

Працює **на твоєму Mac** (скани в той час, коли Mac увімкнений; пропущений через сон чи вимкнення
скан запускається одразу після пробудження/старту) **або на сервері** в Docker — тоді 24/7.

## Структура

```
config.yaml              ← усі налаштування: джерела, фільтри, ліміти, розклад, селектори
.env                     ← токени (Telegram, LLM)
data/cv/                 ← резюме: PDF (uk + en, кладеш свої) і текст для LLM (base_cv.*.yaml — вигаданий приклад)
data/sessions/*.json     ← логін-сесії сайтів (надсилаєш боту)
data/jobs.db             ← база вакансій і відгуків (SQLite)
app/sources/             ← парсери Djinni (RSS), DOU (RSS), robota.ua (API), work.ua (HTML)
app/scorer.py            ← фільтр + LLM-оцінка + лист
app/appliers/browser.py  ← відгук через браузер (Playwright)
app/bot.py               ← Telegram: звіти й команди
tools/login.py           ← запускаєш у себе, щоб залогінитися на сайтах
```

## Запуск на Mac (~10 хв)

```bash
cd job-agent
bash setup_mac.sh                              # venv + залежності + Chromium
open -e .env                                   # токен бота, LLM-ключ
.venv/bin/python tools/login.py djinni         # потім dou, robota, workua — логін один раз
.venv/bin/python -m app.main                   # запуск; напиши боту /start
bash autostart_mac.sh                          # фоновий режим + автостарт після входу
```
Перший скан стартує одразу після запуску. Далі о 09:15 / 13:15 / 18:15; якщо Mac у цей час спав —
скан відбудеться протягом 5 хв після пробудження.

## Запуск на сервері (24/7)

**1. Telegram-бот.** У @BotFather: `/newbot` → отримаєш токен.

**2. Сервер.** Будь-який Linux VPS з 2 GB RAM (Hetzner CX22 або подібний). На ньому:
```bash
curl -fsSL https://get.docker.com | sh
git clone <репозиторій> job-agent   # або scp папку
cd job-agent && cp .env.example .env && nano .env    # токен бота + LLM-ключ
docker compose up -d --build
```
Напиши боту `/start`: він покаже твій chat id. Впиши його в `.env` як `TELEGRAM_CHAT_ID` і виконай `docker compose restart`.

**3. Логіни на сайтах** (на своєму Mac, для кожного сайту):
```bash
pip install playwright pyyaml && python -m playwright install chromium
python tools/login.py djinni     # потім dou, robota, workua
```
Відкриється браузер → логінишся → Enter. Файл `sessions/djinni.json` надішли боту: він збереже його на сервері і видалить повідомлення з чату.

**4. Тест.** За замовчуванням `dry_run: true`: агент заповнює форми, але **не натискає «Надіслати»** і шле скріншоти. Коли переконаєшся, що все правильно, напиши боту `/dryrun off`.

## Команди бота

| | |
|---|---|
| `/status` | стан, сесії, налаштування |
| `/scan` | запустити скан зараз |
| `/today` | що надіслано сьогодні |
| `/job djinni:123` | деталі вакансії, оцінка і лист |
| `/pause` `/resume` | зупинити / відновити відгуки (скан і звіти продовжуються) |
| `/dryrun on\|off` | тестовий / бойовий режим |
| `/limit 15` | максимум відгуків на день |
| `/minscore 70` | мінімальний бал для автовідгуку |

## Захисти

- Денний ліміт відгуків (15) і випадкові паузи між ними.
- Не відгукується в ту саму компанію частіше, ніж раз на 30 днів.
- Казино, ставки й криптовалюти в чорному списку: за назвою + LLM перевіряє сферу компанії.
- Якщо після «Надіслати» немає підтвердження, повторно **не** надсилає, а пише «перевір».
- Коли сесія на сайті злітає, бот присилає 🔑-повідомлення: треба повторити крок 3 для цього сайту.

## Відомі обмеження

- **Форми відгуків на сайтах відрізняються і змінюються.** Селектори лежать у `config.yaml → selectors`. Перші запуски в dry_run потрібні саме для того, щоб звірити їх по скріншотах.
- **work.ua** блокує деякі серверні IP (403). Якщо так буде на твоєму VPS, бот напише про це в «Помилках», а решта джерел працюватиме далі.
- **DOU:** частина вакансій веде на сайт компанії. Такі потрапляють у «Потрібно вручну» з посиланням.
- **Правила сайтів:** автоматизація відгуків може суперечити правилам Djinni/DOU/robota/work.ua. Помірний ліміт знижує ризик блокування акаунта, але не прибирає його повністю.
