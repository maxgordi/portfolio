# VoxMatch Простой — версия 2

Скинул все дубли разом → программа сама выбрала эталон, выровняла дубли по времени и нотам и собрала **комп из лучших фраз**. Любую фразу можно заменить на вариант из другого дубля колёсиком мыши.

Голос не пересобирается вокодером. Живая запись идёт через движок Rubber Band (R3): он растягивает её по времени и сдвигает высоту с сохранением тембра. Всё делается одним проходом, без склеек.

## Запуск
```
cd voxmatch-lite && ./start_mac.command
```

## Как работать
1. **Скиньте все дорожки** в верхнюю зону: из Cubase, из Finder или кликом.
2. **Эталон.** Если никакую дорожку не отметить ★, программа выберет эталон сама: самый «типичный» дубль, то есть ближе всех к остальным. Сменить эталон — клик по ☆ у нужной дорожки.
3. **Обработка начинается сама** (галочку «Сразу обрабатывать» можно снять в ⚙). Для каждой дорожки программа определяет тип:
   - **унисон** (дабл) — тайминг и ноты подгоняются под эталон, дорожка участвует в компе;
   - **гармония** (бэк в терцию, квинту…) — выравнивается только тайминг, ноты не трогаются;
   - **октава** — октава сохраняется.
4. **Комп.** Эталон режется на фразы, и каждая фраза каждого дубля получает оценку от 0 до 100. Оценка учитывает:
   - чистоту нот по сравнению с общей мелодией всех дублей, до коррекции;
   - те ли слова спеты и всё ли на месте;
   - насколько сильно пришлось растягивать фразу;
   - перегруз.

   Комп собирается из лучших фраз. Стыки делаются короткими кроссфейдами в паузах.

## Лента «Комп» (над волнами)
- Каждый блок — фраза. На блоке подписано, из какого дубля она взята (Э — эталон, Д1, Д2…), её оценка и, если есть, пояснение («ноты ±40 ц», «другие слова/звук», «не всё спето»…).
- **Колёсико на блоке** листает варианты: вверх — к лучшему, вниз — к худшему. Фраза сразу играет по кругу.
- **Клик** по блоку — слушать эту фразу по кругу.
- **Правый клик** — список всех вариантов с оценками.
- «Лучшие фразы» — вернуть автоматический выбор.
- «⇱ Комп → Cubase» — перетащите эту плашку на дорожку Cubase. «Сохранить комп» сохраняет файл в папку «VoxMatch Простой».

## Волны
- Оранжевая — эталон. Бирюзовая поверх неё — выбранный дубль после обработки. Снизу — тот же дубль «как спето».
- **Красные полосы** — места, где дубль сильно тянули или он не похож на эталон. Их стоит послушать.
- Клик ставит курсор. Протяните мышью — получится петля.
- Колёсико — масштаб, Shift+колёсико — прокрутка, двойной клик — показать весь файл.

## Плеер и клавиши
- **Пробел** — играть/пауза.
- **1 / 2 / 3 / 4** — эталон / дубль до / результат / комп. Переключение без остановки, позиция сохраняется.
- **↑ / ↓** — лучший или худший вариант фразы под курсором.
- **← / →** — соседняя фраза.
- **L** — петля.
- **E** — подмешать эталон тише, чтобы слышать совпадение.

## Настройки (⚙)
Тайминг, жёсткость, питч, макс. растяжение, сохранение тембра, «бэки в гармонию — ноты не трогать». После изменения настроек нажмите «Применить ко всем».

Дорожки, эталон и выбор фраз запоминаются: при следующем запуске сессия откроется сама.
Бэкап первой версии лежит в папке «VoxMatch Простой — бэкап v1».
