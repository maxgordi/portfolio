PressVoice Local Test — бесплатный перевод на этом Mac (без интернета)
=====================================================================

Запуск: двойной клик по «PressVoice Local Test (окно).command».
Сначала закройте окно PressVoice Rust — оно слушает ту же клавишу.

В окне:
  Распознавание — Whisper (точнее, ~2 с) или Vosk (быстрее, больше ошибок, только ru/en);
  Я говорю на / Перевод на — 12 языков;
  Голос перевода — русские: Денис, Дмитрий, Руслан, Ирина; английские: Ryan, Alan,
    Lessac, Amy (уже скачаны); для других языков голос скачивается при выборе;
  Микрофон, Наушники.

Держите правый ⌥ Option (или большую кнопку мышью) и говорите.

Отправлять:
  По фразам — каждая фраза переводится сама, как только вы сделали паузу
              (длина паузы выбирается: 0,5 / 0,7 / 1,0 / 1,5 с), можно говорить
              долго, не отпуская клавишу — переводы идут один за другим;
  Целиком   — всё сказанное переводится после отпускания клавиши.

Перевод звучит через ~3 с после конца фразы (Whisper; из них ~0,7 с — ожидание паузы)
или ~1 с (Vosk). Перевод начинается ПОСЛЕ фразы, не по ходу речи.

Каждая фраза с временем каждого шага — в окне и в local_test.log.
Настройки окна сохраняются в ~/.config/pressvoice/local_test.json.
