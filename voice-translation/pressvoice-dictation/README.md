# PressVoice

Голосовой ввод в стиле Superwhisper: держишь клавишу, говоришь, отпускаешь, и текст вставляется туда, где стоит курсор. Распознавание идёт через OpenAI.

| Платформа | Что запускать | Технологии |
|---|---|---|
| **Windows 10/11** | установщик `PressVoice-Setup-<версия>.exe` | Qt (PySide6), pynput, Inno Setup |
| **Linux (X11)** | `PressVoice-<версия>-x86_64.AppImage` | то же, что для Windows |
| **macOS 14+** | `PressVoice-<версия>-macOS-arm64.dmg` (Apple Silicon) или `…-x86_64.dmg` (Intel) | rumps, AppKit |

## Когда появляется текст

Переключатель **Text** в настройках (на Mac он выглядит как «Удержание / Переключение»):

| Режим | Что происходит | Модель | Цена |
|---|---|---|---|
| **Целиком** *(по умолчанию)* | Весь текст вставляется через 1–2 с после того, как отпустил клавишу | выбранная в **Model** | как у модели |
| **По фразам** | Пока говоришь, каждая фраза появляется примерно через секунду после паузы. Точность как у режима «целиком» | выбранная в **Model** | как у модели |

- «По фразам» работает и при удержании клавиши, и в режиме «нажал — пошла запись, нажал ещё раз — стоп».
- **Стили** применяются только в режиме «целиком»: по фразам текст печатается сразу, и переписать его уже нельзя.
- После диктовки весь текст попадает в **History**.
- **macOS:** текст печатается как с клавиатуры, буфер обмена не трогается.
- **Windows и Linux:** текст вставляется кусками через буфер обмена (Ctrl+V). После диктовки в буфере остаётся весь текст. Удобнее всего с клавишей Right Ctrl, она стоит по умолчанию. С Right Alt или Right Shift зажатая клавиша добавляется к Ctrl+V, и некоторые программы понимают это сочетание иначе.

## Языки интерфейса

16 языков: English, Українська, Русский, Español, Português (Brasil), Deutsch, Français, Italiano, Polski, Türkçe, Nederlands, 简体中文, 繁體中文, 日本語, 한국어, Bahasa Indonesia.

- **Выбор языка.** По умолчанию берётся язык системы: на Windows — язык интерфейса, на macOS — список предпочитаемых языков, на Linux — переменная `LANG`. Если язык системы не поддерживается, интерфейс будет на английском. Выбрать вручную можно в Settings → **Language**, переключение происходит сразу, без перезапуска.
- **Что переводится:**
  - меню и окна;
  - уведомления;
  - установщик Windows;
  - системный запрос macOS на доступ к микрофону;
  - описание программы в меню Linux.
- **Распознавание речи от языка интерфейса не зависит:** OpenAI сам определяет язык речи.
- **Добавить язык:** создать `i18n/locales/<код>.json` по образцу `en.json` и добавить строку в `i18n.LANGUAGES`. Тест `tests/test_i18n.py` проверит, что все строки на месте, а подстановки `{…}` совпадают.

## Windows: установка

1. Запусти `PressVoice-Setup-1.0.5.exe`. Установщик говорит на языке Windows. Галочки «ярлык на рабочем столе» и «автозапуск» включены по умолчанию. Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\PressVoice`.
   - Установщик не подписан сертификатом, поэтому Windows может показать «Windows protected your PC». Нажми **More info → Run anyway**.
2. После установки PressVoice запустится сам и откроет **Settings**. Вставь ключ OpenAI (https://platform.openai.com/api-keys) и нажми **Save**.
3. Кликни в любое текстовое поле, **зажми правый Ctrl**, скажи фразу и отпусти клавишу. Текст вставится через 1–2 секунды.

Иконка микрофона сидит в трее у часов. Если её не видно, нажми стрелку **^**. Цвет иконки показывает состояние:

- синяя — ожидание;
- красная — идёт запись;
- оранжевая — распознавание;
- фиолетовая — применяется стиль.

**Меню трея** открывается любым кликом по иконке:

| Пункт | Что делает |
|---|---|
| History | Последние фразы. Клик копирует фразу в буфер обмена |
| Style | Постобработка текста через ИИ. Пункт *Edit Styles…* открывает редактор стилей |
| Settings | Ключ, модель, микрофон, клавиша, режим, автозапуск |
| Open Log Folder | Открывает папку с логом для разбора проблем |

Если запустить PressVoice из меню Пуск, когда он уже работает, откроются его настройки. Вторая копия при этом не запустится.

### Настройки

| Поле | Что делает |
|---|---|
| **Model** | Модель распознавания. **↻ Refresh** загружает у OpenAI актуальный список моделей, доступных твоему ключу. Так появятся и модели, вышедшие позже. В поле можно вписать любой id вручную. Если модель недоступна, PressVoice переключится на `gpt-4o-mini-transcribe` и предупредит об этом |
| **Hotkey** | Right Ctrl, Right Alt, Right Shift, Menu, Pause, Scroll Lock, Insert, F13–F19 |
| **Recording mode** | *Push-to-talk*: держишь клавишу, пока говоришь. *Toggle*: нажал — запись пошла, нажал ещё раз — остановилась |
| **Text** | Целиком или по фразам, см. «[Когда появляется текст](#когда-появляется-текст)» |
| **Start with Windows** | Автозапуск при входе в систему |

Если во время записи нажать другую клавишу (например, Right Ctrl+C), запись отменится. Обычные сочетания клавиш не превращаются в диктовку.

### Модели (октябрь 2026)

| Модель | Цена | Комментарий |
|---|---|---|
| `gpt-transcribe` | $0.0045/мин | Новейшая (июль 2026). Лучше справляется с акцентами, цифрами, терминами и шумом |
| `gpt-4o-mini-transcribe` *(по умолчанию)* | $0.003/мин | Самая дешёвая |
| `gpt-4o-transcribe` | $0.006/мин | Предыдущее поколение |
| `whisper-1` | $0.006/мин | Устаревшая |

Модели `gpt-live-transcribe` и `gpt-realtime-whisper` работают только в потоковом режиме, поэтому в этом списке их нет. `gpt-4o-transcribe-diarize` нужна для разметки спикеров и для диктовки не подходит.

### Если «Microphone error» / «Windows is blocking the microphone»

Windows запрещает обычным программам доступ к микрофону, если в настройках приватности выключен хотя бы один переключатель. В логе это выглядит как `Unanticipated host error … [MME error 1]`. PressVoice сам определяет, какой переключатель выключен, и открывает нужную страницу настроек.

Включить нужно всё на странице **Параметры → Конфиденциальность и защита → Микрофон**:
- «Доступ к микрофону»;
- «Разрешить приложениям доступ к микрофону»;
- **«Разрешить классическим приложениям доступ к микрофону»** (в самом низу страницы).

Проверить микрофон можно в Settings, кнопкой **Test** рядом с выбором микрофона.

### Ограничения Windows

- **Окна администратора.** Windows не даёт обычной программе отправлять нажатия в окна, запущенные от администратора. Туда PressVoice вставить текст не сможет: он останется в буфере обмена, и его можно вставить вручную через Ctrl+V.
- **Где лежат данные:**
  - настройки и история — `%APPDATA%\PressVoice`;
  - лог — `%LOCALAPPDATA%\PressVoice\pressvoice.log`.
- **Удаление.** Через «Параметры → Приложения». Настройки и история при этом сохраняются.

### Проверка на своём ПК (чек-лист)

На CI-машинах нет микрофона, поэтому вот что стоит проверить руками:

- [ ] Установка проходит, после неё открывается Settings.
- [ ] **↻ Refresh** показывает «Found N models. The key works.»
- [ ] В Settings виден твой микрофон. Если нет, выбери «System default».
- [ ] Диктовка правым Ctrl в Блокнот, браузер, Word и Telegram.
- [ ] Диктовка при русской раскладке.
- [ ] После перезагрузки Windows иконка снова в трее.
- [ ] Диагностика: `"%LOCALAPPDATA%\Programs\PressVoice\PressVoice.exe" --selftest "%USERPROFILE%\Desktop\selftest.json"` создаёт отчёт на рабочем столе.

## macOS: установка

1. Открой `PressVoice-1.0.5-macOS-arm64.dmg` (для Intel-Mac — `…-x86_64.dmg`) и перетащи **PressVoice** в **Applications**.
2. Запусти PressVoice из Launchpad или Программ. В строке меню появится 🎙, и откроется Settings: вставь ключ OpenAI (Cmd+V работает) и нажми **Save**.
3. macOS попросит доступ к **Универсальному доступу** (Accessibility). Без него программа распознаёт речь, но macOS **молча блокирует вставку** (⌘V). Включи PressVoice в *Системные настройки → Конфиденциальность и безопасность → Универсальный доступ*. Перезапускать программу не нужно: она подхватит разрешение сама и сообщит «PressVoice is ready». Если разрешения нет, после диктовки придёт уведомление «Copied — press ⌘V», и нужная страница настроек откроется сама.
4. **Зажми правый ⌘**, скажи фразу и отпусти клавишу. При первой записи macOS спросит доступ к микрофону, нажми «Разрешить».

Как ведёт себя программа:
- **Автозапуск при входе** включается сам при первом запуске. Выключить можно галочкой *Start at login* в Settings. Если программа вдруг упадёт, macOS перезапустит её сама.
- **Повторный запуск.** Если открыть PressVoice ещё раз, когда он уже работает, откроются его настройки.
- **Где лежат данные:**
  - настройки и история — `~/.config/pressvoice` (общие с версией из исходников);
  - лог — `~/Library/Logs/PressVoice/pressvoice.log`.

**Предупреждение macOS при первом запуске.** DMG не нотаризован Apple: для этого нужен платный Apple Developer ID. Поэтому для скачанного из интернета файла macOS может написать «Apple не может проверить…». Тогда открой *Системные настройки → Конфиденциальность и безопасность* и нажми **«Всё равно открыть»**.

**Обновление.** Перетащи новую версию поверх старой. Все сборки подписаны одним и тем же сертификатом PressVoice, поэтому разрешения Универсального доступа и микрофона сохраняются между версиями.

*Переход с 1.0.0/1.0.1.* У этих версий был другой идентификатор, общий со старым ярлыком из папки проекта. Из-за этого macOS мог показывать переключатель включённым, хотя он не действовал. Начиная с 1.0.2 идентификатор `com.pressvoice.mac`, поэтому разрешение нужно дать один раз заново.

Самопроверка: `/Applications/PressVoice.app/Contents/MacOS/PressVoice --selftest ~/Desktop/selftest.json`

## Linux

```bash
chmod +x PressVoice-1.0.5-x86_64.AppImage
./PressVoice-1.0.5-x86_64.AppImage
```

- Нужна сессия **X11**. В Wayland система не даёт программам перехватывать клавиши глобально.
- Чтобы в GNOME была видна иконка в трее, нужно расширение *AppIndicator*.
- Если AppImage не запускается из-за FUSE, установи `libfuse2` или запусти с ключом `--appimage-extract-and-run`.
- Нужна glibc 2.35 или новее: Ubuntu 22.04+, Debian 12+, Fedora 36+.

## Сборка

Сборка и тесты запускаются в GitHub Actions автоматически при каждом push (см. [.github/workflows/build.yml](.github/workflows/build.yml)):

- на `windows-2022` (≈ Windows 10) и `windows-2025` (≈ Windows 11):
  - unit-тесты;
  - end-to-end тесты с настоящим хуком клавиатуры и вставкой, в том числе при русской раскладке;
  - сборка exe и его `--selftest`;
  - сборка установщика, тихая установка и удаление с проверками;
- на `ubuntu-22.04`: тесты под Xvfb, сборка AppImage и его selftest.

Готовые файлы лежат в **Actions → нужный запуск → Artifacts**. Если запушить тег `v*`, установщик и AppImage попадут в GitHub Release.

Для macOS сборка идёт на `macos-15` (Apple Silicon) и `macos-15-intel`:
- сборка `.app` и его selftest;
- сборка DMG;
- установка из DMG в /Applications и повторный selftest;
- end-to-end тесты настоящего приложения: горячая клавиша → «запись» → вставка текста в окно другой программы, первый запуск, повторный запуск.

Собрать без GitHub:
- **Windows** — установи Python 3.12 и Inno Setup 6, затем запусти `build_windows.bat`;
- **macOS** — запусти `./build_mac.sh`, результат появится в `dist/PressVoice-*.dmg`.

Разработка:

```bash
pip install -r requirements-qt.txt -r requirements-dev.txt
python -m pytest
python main_qt.py          # Windows/Linux-версия из исходников
```
