# PressVoice Live — Soniox

Копия PressVoice Rust (Gemini), в которой переводит **Soniox**:
**stt-rt-v5** (распознавание с переводом по ходу речи) и **tts-rt-v2** (голос перевода).
Оригинал на Gemini лежит в `../realtime-translator-gemini` и работает как раньше.

Запуск: двойной клик по **«PressVoice Soniox — переводчик (окно).command»**.
Ключ — поле `soniox_api_key` в `~/.config/pressvoice/config.json`.

## Что отличается от Gemini-версии
- **«Мой перевод: голосом / только текстом»** и **«Перевод собеседника: голосом / только
  текстом»**. «Только текстом» — перевод виден в панели, голос не синтезируется и не
  оплачивается.
- **Голос перевода** — любой из 200 голосов Soniox (каждый говорит на всех языках);
  сверху: Adrian (по умолчанию), русские Andrei / Kirill / Vadim, украинские Taras / Bohdan.
- **Ваши клоны голоса** — программа при запуске сама берёт из Soniox все готовые клоны
  вашего проекта (api.soniox.com/v1/voices) и показывает их первыми: «★ Имя — ваш клон».
  Клон создаётся в консоли Soniox (Voices → Create voice) в ТОМ ЖЕ проекте, что и ключ.
- **«Скорость голоса»** для каждой стороны: 0,8× … 1,3× (как на YouTube). Soniox сам
  озвучивает быстрее — без искажений и задержки; быстрее — ещё и дешевле. Меняется сразу.
- Нет «разогрева» и «коррекции тембра» — голос задаётся выбором голоса.
- Языки — 60 языков Soniox.
- Свои файлы: `live_window_soniox.json`, `usage_soniox.json`, лог `live_soniox.log`.

## Панели текста
Слева — ваш язык, справа — язык собеседника: «Я говорю» | «Собеседник слышит (перевод)»,
ниже «Я слышу (перевод)» | «Собеседник говорит».

## Как работает
Одна сессия распознавания на сторону, звук идёт только пока держите клавишу (или пока
говорит собеседник), между нажатиями — keep-alive. В конце нажатия `finalize`: хвост фразы
приходит за ~0,15 с. Перевод приходит кусками по ходу фразы; каждый готовый кусок сразу
озвучивается на одном тёплом соединении (первый звук ~0,3–0,4 с).

Замер на тех же фразах (7 и 10,6 с), честно в реальном времени:

| | Soniox | Gemini |
|---|---|---|
| голос перевода начинается (от начала фразы) | 3,0–3,9 с | 2,7–2,9 с |
| голос заканчивается после конца речи | 1,5 с | 2,3–2,4 с |
| цена этих фраз | $0,0015–0,0028 | $0,0055–0,0065 (+$0,005 разогрев) |

Цены (soniox.com/pricing): распознавание с переводом ≈ $0,18/час звука, голос ≈ $0,70/час
речи. Перевод голосом в одну сторону ≈ $0,89/час, только текстом ≈ $0,18/час.

## Баланс
Как в Gemini-версии: сумма вводится кнопкой «Указать баланс…» (из консоли Soniox), расход
считается по обработанному звуку и секундам голоса. «Хватит на…» учитывает режимы обеих сторон.

## Для разработки
```
cargo test --release                                     # 33 теста без сети
cargo test --release -- --ignored --test-threads=1      # с устройствами (захват — из Терминала)
./target/release/pressvoice-soniox --simulate фраза.wav --from ru --to en [--voice Andrei | --text-only] [--save out.wav]
```
`src/soniox.rs` — сессии Soniox (распознавание + голос); остальное как в Gemini-версии
(см. `CLAUDE.md`).
