# «На телевизор»: расширение Chrome для LG 42LF652V

Кнопка на YouTube отправляет видео на телевизор. Оно само начинает играть в приложении YouTube на ТВ с той же секунды, а на Маке ставится на паузу.

## Установка (один раз)

1. **Помощник.** В Finder открой `~/Public/tvcast` и дважды кликни «Установить помощник.command».
   Пароль не нужен. В конце должна появиться строка «✓ Телевизор в сети» (или «выключен»).
   Если macOS не даёт открыть файл: правый клик → «Открыть» → «Открыть».
2. **Расширение.**
   1. В Chrome открой `chrome://extensions`.
   2. Справа вверху включи «Режим разработчика».
   3. Нажми «Загрузить распакованное» и выбери папку `~/Public/tvcast/chrome-extension`.
      В Finder: ⇧⌘G, вставь путь, «Открыть».
   4. Проверь ID расширения: `ohlnmnflkccnigplbpgidflfdmfhbeah`. Помощник отвечает только ему.
   5. Нажми на значок пазла справа от адресной строки и закрепи «На телевизор (LG)».
3. **Разрешение «Локальная сеть».** Оно нужно в macOS 15.
   - При первом нажатии кнопки macOS может спросить «Google Chrome хочет найти устройства в локальной сети». Ответь «Разрешить».
   - Если окно не появилось, а расширение пишет «macOS не пускает Chrome в домашнюю сеть»: «Системные настройки → Конфиденциальность и безопасность → Локальная сеть» → включи Google Chrome → перезапусти Chrome.
4. **Включение телевизора по сети** (делается на телевизоре): «Настройки → Общие → Mobile TV On» (включение по Wi-Fi) → «Вкл».

## Как пользоваться

- **Кнопка в плеере.** Значок телевизора стоит справа на панели плеера, рядом с субтитрами и настройками.
- **Shorts.** Справа внизу экрана появляется кнопка «На телевизор».
- **⌥T (Option+T)** на странице видео. Сменить клавишу: `chrome://extensions/shortcuts`.
- **Правый клик по странице видео** → «На телевизор».
- **Правый клик по ссылке на видео** (в том числе на других сайтах) → «Открыть ссылку на телевизоре». Видео пойдёт с начала или с `t=` из ссылки.
- **Значок расширения.**
  - Точка на значке: зелёная — телевизор в сети, серая — выключен, красный «!» — проблема.
  - В окошке: громкость − / +, пауза / продолжить, выключить или включить телевизор.

Сколько времени занимает отправка (замерено на твоём телевизоре):
- YouTube на ТВ уже открыт: около 10 с, почти всё время телевизор подгружает видео;
- YouTube закрыт (ТВ на каналах): около 30 с, из них ~15 с само приложение запускается на ТВ.

## Как это устроено

- `chrome-extension/` — расширение (Manifest V3). Само с телевизором не общается и всё передаёт помощнику.
- `helper/tvcast_host.py` — помощник на Python (только стандартная библиотека). Chrome запускает его на каждую команду (Native Messaging).
  - Регистрация на ТВ — тот же подписанный манифест и тот же ключ `~/.lgtv_client_key`, что в `tvremote.py`. Подтверждать на ТВ заново не нужно.
  - Видео запускается через **YouTube Lounge API**, тот же канал, что у кнопки «Трансляция» в телефоне:
    1. screenId телевизора берётся по DIAL (`Application-URL` → `/apps/YouTube`).
    2. По screenId получается lounge-токен.
    3. Команда `setPlaylist` с videoId и секундой запускает видео.
  - Если YouTube на ТВ закрыт или выпал из канала (так бывает после конца видео), помощник запускает его по DIAL и ждёт, пока приложение заново подключится.
  - Если приложение не берёт видео (например, висит экран «Кто смотрит?»), помощник нажимает ENTER через сокет указки webOS и пробует ещё раз.
  - Если ТВ выключен: Wake-on-LAN на оба MAC-адреса ТВ (Wi-Fi `AA:BB:CC:DD:EE:01` и проводной `AA:BB:CC:DD:EE:02`), затем ожидание порта 3000 до 35 с. Если ТВ не проснулся, честное сообщение «включи пультом».
  - Если роутер выдал ТВ другой IP, помощник находит ТВ заново по SSDP.
- Запомненные данные (IP, MAC-адреса, screenId): `~/.config/tvcast/state.json`.
- Лог: `~/Library/Logs/tvcast-helper.log`.

Почему без помощника нельзя:
- расширение Chrome не умеет UDP, а без него нет ни Wake-on-LAN, ни поиска ТВ (SSDP);
- запрос к `http://192.168.1.50` со страницы расширения тоже упирается в разрешения Chrome на частную сеть.

## Проверка из Терминала (без Chrome)

```
cd ~/Public/tvcast/helper
./tvcast_host.py status
./tvcast_host.py cast "https://www.youtube.com/watch?v=aqz-KE-bpKQ" 120
./tvcast_host.py playpause
./tvcast_host.py volup      # voldown, off, wake
```

## Если что-то не так

| Сообщение | Что сделать |
|---|---|
| Не установлен помощник | Запусти «Установить помощник.command», перезапусти Chrome |
| macOS не пускает Chrome в домашнюю сеть | Разрешение «Локальная сеть» для Chrome (п. 3 установки) |
| Нужно подтвердить подключение на телевизоре | На ТВ нажми пультом «Да», затем кнопку ещё раз |
| Телевизор не включился по сети | Включи пультом. После отключения из розетки ТВ может не просыпаться по сети до первого включения пультом |
| YouTube на телевизоре не ответил | Посмотри на экран ТВ, закрой окно или вопрос пультом, нажми ещё раз |
